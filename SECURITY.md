# Security Policy

## Supported versions

Only the newest published beta receives security fixes during early development.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature when it is available on the
repository. Do not open a public issue for archive extraction, path traversal,
arbitrary deletion, credential, or private-data vulnerabilities.

Include the app version, Android version, storage provider, reproduction steps, and
the smallest safe test archive needed to reproduce the problem. Remove game files,
save data, tokens, and private filesystem details before submitting a report.
