# Notice

Balatro Mod Manager for Android is a native Android mod manager inspired directly by
Balatro Mod Manager by skyline69 and contributors:

https://github.com/skyline69/balatro-mod-manager

This project targets user-created Android Balatro builds made with Lovely Mobile
Maker and operates through Android Storage Access Framework permissions granted
by the user.

This project does not distribute Balatro, does not distribute game APKs, and does
not modify the official Play Store version.
