# Balatro Mod Manager 0.2.1

## Interface

- Adapted catalog and installed-mod grids to the available screen width on phones, tablets, and landscape layouts.
- Reworked wide-screen headers and installed-mod actions, and added a compact navigation bar for short screens.
- Made card density control minimum card width and set large cards as the default.
- Expanded the mod-detail loading and installation progress bars to use their available width, including landscape layouts.
- Removed the duplicate system refresh spinner during the first catalog load.
- Kept dark mode as the default.
