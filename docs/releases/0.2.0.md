# Balatro Mod Manager 0.2.0

## Catalog

- Switched the Balatro catalog to Thunderstore.
- Added full version-specific READMEs, dependency details, and installation of selected package versions.
- Cached README content for quick display, with background refresh for older entries.
- Filtered packages with known mobile incompatibilities or desktop-only archives.

## Installed mods

- Added ZIP import for single mods and archives containing multiple mod folders.
- Added management for mods installed outside Thunderstore, including enable, disable, and remove actions.
- Added a notice for newer GitHub releases.

## Interface

- Updated cards for square package artwork and adjustable 3-, 2-, and 1-column layouts.
- Set dark mode and two cards per row as the defaults.

## Setup

Create a Balatro Android build with [Lovely Mobile Maker](https://lmm.shorty.systems/) and open it once. Then select the parent folder containing ASET in the mod manager. Android 8 or newer is required.
